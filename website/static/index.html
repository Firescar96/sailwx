Forecast Stability (day-over-day: how much has each model's own forecast changed run to run?)

Not the same as Model Accuracy (that's error vs. reality) -- this shows how much each model's predicted value for the SAME upcoming hour has shifted across its last few runs, independent of whether it turns out to be right. A tight band = the model has been consistent; a wide band = it's still making up its mind.

CBI Flag Prediction (Bayesian: P(flag color | forecast wind + gust), from one selected model)

Not the same as the accuracy chart above -- this doesn't measure model error, it estimates "given this model's wind AND gust forecast, how likely is each flag color" using CBI's own historical wind/gust-vs-flag pairing (bucketed by the higher of the two, since a gusty light-wind hour behaves like a stronger steady wind), with Bayesian smoothing so sparse wind ranges don't look falsely certain.

Wind Prediction (Bayesian: P(actual wind bucket | forecast wind), from one selected model)

Not the same as the accuracy chart above -- instead of "how far off is the model on average", this estimates "given this model's forecast wind, how likely is the REAL wind to fall in each range", using this location's own historical forecast-vs-observed wind pairing, with Bayesian smoothing.

Wind Rose (direction + speed frequency: observed vs. forecast)

Only shown at locations with real wind direction/speed sensors (not CBI, which has no wind sensor of its own). Compares the historical distribution of observed wind direction/speed against a selected model's own forecast distribution over the same recent period.

Gustiness (extra wind above the sustained speed)

Primary chart: gust minus sustained speed, in knots -- directly answers "how many extra knots could hit me," and unlike a ratio, a +5kt gust means the same thing whether the base wind is 2kt or 20kt. Below shows the underlying sustained-vs-gust relationship as a scatter, colored by gust/sustained ratio across the full wind range (note: at very light wind, dividing by a near-zero base wind can make the ratio swing wildly even for a small absolute gust -- cross-check the color against the actual sustained/gust values shown on hover). Optionally extends 1 day into the future using a selected forecast model's own wind+gust forecast -- forecast-derived points are shown with a dashed line / hollow marker, distinct from solid observed data.
