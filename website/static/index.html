CBI Flag Prediction (Bayesian: P(flag color | forecast wind), from one selected model)

Not the same as the accuracy chart above -- this doesn't measure model error, it estimates "given this model's wind forecast, how likely is each flag color" using CBI's own historical wind-vs-flag pairing, with Bayesian smoothing so sparse wind ranges don't look falsely certain.

Wind Prediction (Bayesian: P(actual wind bucket | forecast wind), from one selected model)

Not the same as the accuracy chart above -- instead of "how far off is the model on average", this estimates "given this model's forecast wind, how likely is the REAL wind to fall in each range", using this location's own historical forecast-vs-observed wind pairing, with Bayesian smoothing.

Wind Rose (direction + speed frequency: observed vs. forecast)

Only shown at locations with real wind direction/speed sensors (not CBI, which has no wind sensor of its own). Compares the historical distribution of observed wind direction/speed against a selected model's own forecast distribution over the same recent period.

Gust Factor (gust speed ÷ sustained speed)

A ratio near 1.0 means steady wind; a high ratio means gusty, variable conditions that can be more hazardous to sail in than steady-but-stronger wind of the same average speed. Only shown at locations with real gust sensor data.

Data source: local DuckDB weather database (read-only). Times shown in UTC.
